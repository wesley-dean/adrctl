## Documentation Build

This landing page is generated during documentation builds.  The framing in
`README.intro.md` and `README.outro.md` is maintained source; the linked ADR list
between them is generated by a pinned released adrctl artifact.  The composite
`doc/adr/README.md` and Doxygen output under `doc/reference/` are intentionally
ignored derivative state.

Using a released adrctl artifact here keeps documentation generation on the public
`generate toc` interface rather than depending on unreleased implementation
internals.  The repository's current source remains the subject being documented;
the released tool owns only mechanical ADR discovery and TOC serialization.
